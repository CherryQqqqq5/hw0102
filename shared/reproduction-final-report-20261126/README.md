# 最终报告生成与PDF校验程序

本目录保存当前两份PDF的生成、检查和打包程序。报告按目的、方法、设置、步骤、结果、分析和结论组织，详细逐题记录随包提供；[方法与数据来源](../REFERENCES.md)单独列明。`SOURCE_MANIFEST.json`和`SHA256SUMS`记录当前程序的摘要。

报告使用ReportLab与macOS的简体黑体Heiti SC，常规正文和加粗标题分别嵌入Light与Medium字重。检查程序核对章节顺序、字体、关键数字、链接和页面边界；提交包的`--focused`选项只收录报告、完整共用代码、相关配置及报告使用的运行记录。

实验数据、逐题工具轨迹与复算入口见[最终结果目录](../../作业二/evidence/performance75-final-20261126/)。九个实验运行版本保存在相邻源码快照，按各题记录选择。

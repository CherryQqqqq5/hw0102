# 最终报告生成与PDF校验程序

本目录保存当前两份PDF的生成、检查和打包程序。报告正文集中于方法、结果、成本、案例与消融；报告数据及实验评分沿用已核对版本。`SOURCE_MANIFEST.json`和`SHA256SUMS`记录当前程序的摘要。

报告使用ReportLab与macOS的Arial Unicode字体，从完整报告数据及对应审查记录生成。检查程序核对全部75题、关键数字、链接与页面边界；提交包的`--focused`选项只收录报告、完整共用代码、相关配置及报告使用的运行记录。

实验数据、逐题工具轨迹与复算入口见[最终结果目录](../../作业二/evidence/performance75-final-20261126/)。九个实验运行版本保存在相邻源码快照，按各题记录选择。

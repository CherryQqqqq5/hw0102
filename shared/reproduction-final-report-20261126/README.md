# 最终报告生成与PDF校验程序

本目录保存两份正式PDF实际使用的最终报告程序，以及对应的全量文字、数字、链接和页界校验程序。`work/render_hy4_final_reports.py` 替代相邻 `reproduction-report-tools-20261126` 中的同名历史版本；相邻目录保持原文件与摘要，其他导出和复现模块继续使用对应来源版本。

最终报告从真实完整的报告数据读取独立重复的配对汇总，使用其中的请求、词元、中位耗时和累计耗时。原始分组统计与配对汇总的字段名不同，本版本修正了该接口读取，未改动实验、原评分、完整性要求或费用校验。旧内部成本预览未覆盖真实报告数据的这一接口，首次正式生成的异常保留在后续独立审查中。

`SOURCE_MANIFEST.json`与`SHA256SUMS`用于核对源码。完整原数据与报告汇总、独立来源审查及最终PDF核查记录见[最终证据目录](../../作业二/evidence/performance75-final-20261126/)。源码与PDF摘要分别登记，旧科学结果审查中的报告程序摘要继续对应其历史版本，不被改写为本版本。

从保留原始工程来源的目录运行报告程序时，需提供完整报告数据与精确对应的最终独立审查；缺少来源或费用证明会拒绝生成正式PDF。PDF生成使用ReportLab及macOS系统中覆盖中文的Arial Unicode字体。脱敏交付件与原件的摘要分开记录；读取已交付评分证据可使用既有离线验证入口，无需模型调用。

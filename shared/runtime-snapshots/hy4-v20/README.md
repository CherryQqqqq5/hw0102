# ReLU查询恢复与提交检查：v20源码快照

本目录保存两个ReLU新会话实际采用的完整课程运行时。75个执行资源与本机冻结目录逐文件相同，摘要和原计划归属见`SOURCE_MANIFEST.json`。仅此任务使用v20，其余题目的历史运行版本继续按各自原计划核对。

相对v18，改动限定于`controller.py`、`terminal_runtime.py`以及新增的`oracle_access.py`、`relu_export.py`。数值恢复器`relu_recovery.py`及逐笔费用校验保持原字节。公开导出器接受输入维数、模块及函数名，生成含完整数值恢复器的独立脚本；它不接收隐藏宽度、私有权重或工程验证生成的候选。

两个新会话均由`hy4flash-free`真实执行，原题评分和最终登记、保护检查均通过，分别有7次和8次属于自身生成的零积分回执。模型实际调用导出器，两个交付脚本均为11305字节。重复中的首次保存因检查待定而不合格，主动检查后的新保存合格；原候选和旧会话记录均保留。详细来源见[真实完成审查](../../../作业二/evidence/relu-v20-20261125/README.md)。

实际工具轨迹未观察到读取oracle实现、模块全局变量或私有权重。访问拒绝与检查待定时的提交拒绝由独立零模型工程回放验证；两个真实会话没有触发这两项拒绝，不据此归因分数提升。命令模式检查具有明确覆盖范围，不构成操作系统隔离。有限查询的一致性与本题原评分通过，也不证明一般网络提取的完整性。

运行上限为500次实际请求、3600秒交互、120秒命令、64000输出词元、0次超时重试；新请求缺少实际模型身份、完整用量或自身零积分回执即停止。重新运行需要自行具备已核实的免费账户、原镜像及依赖；本快照不包含凭据，不授权收费调用，也不表示完整75题评测已完成。

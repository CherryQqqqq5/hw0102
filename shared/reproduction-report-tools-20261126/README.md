# 报告与证据导出程序的后续版本

本目录补充11月26日源码快照之后的报告与导出程序。相邻的 `reproduction-20261126` 保持原942项来源及清单；本目录中的同名逻辑路径是后续版本，原版本和中间版本均按各自摘要保留。评测运行时、原评分器、模型费用校验和既有评分保持对应的冻结版本。

`SELECTION.json` 明确列出复制范围，`SOURCE_MANIFEST.json` 登记原件与交付件的字节数和SHA-256（Secure Hash Algorithm 256-bit，256位安全散列算法）。Python源码和源码历史副本保持字节一致；执行与审查记录通过项目既有脱敏函数处理机器路径，转换前后摘要分别登记。原件摘要仍只对应原始字节，不用于核验经过脱敏的文件。可在本目录执行 `shasum -a 256 -c SHA256SUMS` 核对交付文件。

本次补充包括环境与仿真性能案例、完整成本表，以及限定任务生成私钥的证据导出处理。OpenSSL任务的导出副本保留原分、验证和来源摘要，移除了该题生成的私钥，相关候选不能从交付副本恢复原私钥字节。原费用验证程序保持不变。历史中断记录的原生产者与加强身份核对后的读取程序分别保存，原导出记录不会被改写为由后续版本生成。

使用后续程序分析原工程时，按清单中的逻辑路径选择本目录版本，并同时保留相邻源码快照提供的其余模块。完整统计与报告生成需要对应的评分、轨迹、冻结计划和最终审查记录；源码摘要校验本身不执行模型实验，也不证明报告完成。资格检查的记录与执行源码一并保留，含原始交互的负例目录不随源码发布。生成的正式报告、逐题证据和最终提交包另按各自清单核对。

## 证据索引

- [逐题成绩](evidence/formal-trials.csv)和[覆盖统计](evidence/formal-coverage.json)记录有效评分、通过状态、终止原因、耗时和模型用量。
- [正式运行目录](evidence/formal/)按题目和配置保存工具轨迹、状态摘要、评分输出及可取得的候选产物。`trial.json` 记录每次运行的任务、模型和预算。
- [评分预检](evidence/preflights/)和[预检统计](evidence/preflight-status.json)记录原始状态与参考解的对照结果。试跑、缓存隔离前的尝试、启动失败和提供方重试另存于 `evidence/`。
- [冻结清单及复现方式](../shared/)提供题目来源、版本、排除依据和执行入口。

上传的工具轨迹保留命令、退出码、标准输出与错误输出。各运行的 `model.jsonl` 保留脱敏后的可见请求、结构化响应、错误类型和用量字段。提供方内部推理与会话标识留在本机。可使用[共用统计程序](../shared/course_eval/summarize.py)从上传记录重新计算模型调用数、词元和服务报告费用。

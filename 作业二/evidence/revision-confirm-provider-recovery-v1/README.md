# 重复确认的网络失败尝试

2026年11月5日，第三轮 `tune-mjcf` 的 A 与 B0 在同一时段遇到模型服务域名解析失败。命令行返回码为0，标准输出为空，适配器拒绝将其当作结构化模型响应，Harbor 因运行异常没有启动原题评分。两条 `result.json` 均保留 `scoreable: false`、`passed: null`。

域名解析与直连服务恢复后，两条运行按相同模型、配置、预算和原题规则重新执行；最终记录位于 `revision-confirm-A-v1/`。本目录是恢复前的原始尝试，不计入确认批的90条评分分母，也没有被填为成功或失败。

两次尝试累计21次请求、18次有效响应，其中一次请求超时、一次额外重试，另有两次域名解析错误；服务报告输入词元271,089、输出词元49,284。以上消耗纳入新增累计用量。可见模型日志保留错误类别与域名解析诊断，剔除提供方日志中的本机代理配置及会话标识。

原容器已清理，日志产物中没有完整最终候选，因此不能只补做原题评分。此次恢复没有修改 Agent、任务、阈值或评分器，补跑结果无论正负均纳入确认统计。

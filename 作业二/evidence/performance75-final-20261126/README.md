`joint-summary.json`、`joint-trials.csv`为最终组合；`original225-summary.json`、`original225-trials.csv`保存完整原批次。`report-data.json`汇总报告指标，最终独立来源与轨迹审查、专项修订审查和导出来源另有对应文件。`PROVENANCE.json`区分原件摘要和脱敏交付件摘要。

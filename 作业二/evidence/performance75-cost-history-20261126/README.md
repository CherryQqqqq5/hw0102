# 补充模型与历史中断的费用证据

本目录保存两份已完成校验的过滤导出，供核对额外计算开销与费用证据范围。它们不增加主实验的成功题目数，也不替代完整75题的主实验、同题对照和独立重复。

`nvidia/`保存NVIDIA官方免费端点的已结束补充记录、对应免费政策、实际模型身份、用量及保留的缺口。`index.json`登记71个成员，分别列出原来源和导出文件的SHA-256摘要。逐笔金额未报告时仍为空值；完整用量证明与不完整请求分开保留。该通道的记录独立于Hy4主比较。

`hy4-interruptions/`保存五次已结束、未形成原题评分的机械中断，共45个登记成员。14次请求中，11次具有自身新增身份及实际零积分回执，另3次缺少独立回执；缺失金额和完整用量继续为空值。五次结果均保持`scoreable=false / passed=null`，不作为任务通过或任务失败计入成功率。输入112105、输出5503词元仅对应已返回的已知前缀。

两份导出均使用已有过滤规则，原始评分、回执状态与来源摘要分别核对。Hy4导出的原生成程序与后续严格身份复核程序保留各自版本，原45个成员未因复核而重写。可重建准备目录、变异测试轨迹、账户数据、登录凭据和客户端安装树不在本目录。

本目录只覆盖所列导出。完整主实验、局部修订及更早历史的记录由各自清单维护；不能将本目录的已知部分解释为整个项目的完整用量或全部费用为零。

# 公开探针与Harbor时限修复

2026-11-07，创智v4在36次尝试后停止，保存35条有效评分及1条未评分。未评分位置为modernize-scientific-stack/C0/首轮：原题两项测试均通过，Harbor记录AgentTimeoutError，汇总保持scoreable=false、passed=null。该次测试结果、异常、交互、公开检查及费用全部保留。

公开探针用runpy运行候选程序时，将自己的元数据文件路径留在sys.argv中。带命令行解析的候选会把它当作输入；候选使用sys.exit(0)正常结束时，还会跳过探针末尾的元数据写出。当前修复先单独保存元数据路径，再将候选命令行设为仅含脚本路径，最终始终写出观测记录；非零SystemExit继续传播，仍判执行失败。公开条件、温度均值、实际pandas读取及依赖要求保持。

Harbor原外层时限与内部执行预算均为600秒。外层还覆盖环境识别，因而可能先取消运行线程，虽然内部线程已经按时结束且原评分完成，汇总仍将该位置标为未评分。修复为Terminal的严格预算调用设置630秒Harbor外层时限，内部600秒、24次决策、命令及请求限制保持；容器准备、执行和清理的实测耗时分别保留。原评分器、原任务评分时限及遇到异常时拒绝评分的规则保持。

真实工程回归未调用模型：

- 合成命令行候选在真实公开气温数据上，旧探针分别因命令行参数及正常退出记录失败；新探针两项通过，返回7的候选仍判失败。
- 真实Harbor容器在5秒内部时限结束执行，原外层5秒复现AgentTimeoutError；增加收尾容限后，内部仍在5秒终止且没有截止后动作，原OpenSSL评分正常产生失败结果。
- 科学计算原空解公开检查失败、上游参考公开检查通过，允许的pyproject.toml依赖文件也通过。工程结果不计入正式成功率。

回归证据位于`terminal-boundary-regression-v1`与`climate-probe-control-v2`。Context7查询发生fetch failed；接口参数依据本机Harbor0.25.0命令帮助及源码核对，真实容器已验证。
